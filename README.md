# 🏥 VITC Health Portal

**VITC Health Portal** is a web-based healthcare management platform designed for the VIT Chennai campus. It provides a centralized system for students to find doctors, check availability, book appointments, track appointment status, and send emergency alerts.

The platform includes separate **Patient** and **Admin** views. Patients can manage appointments and access emergency contacts, while administrators can manage doctor profiles, availability, patient records, and appointment requests.

## ✨ Key Features

* 👨‍⚕️ Doctor directory with specialties, shift timings, experience, and availability
* 📅 Doctor availability calendar
* 🗓️ Online appointment booking
* 📋 Appointment status tracking
* 🛠️ Admin dashboard for managing doctors and patients
* ✅ Approve/reject appointment requests
* 🚨 One-click emergency alerts with patient location and details
* 📞 Quick access to helpline, ambulance, pharmacy, and lab contacts

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* Node.js
* SQL
